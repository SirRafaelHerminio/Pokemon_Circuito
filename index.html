04 / Antes de partir

Dúvidas de treinador.

Como mando esta página para meus amigos?

Use “Baixar página HTML” no rodapé e envie o arquivo. Cada pessoa abre a página e clica em Jogar agora, sem selecionar ROM. A página HTML baixada funciona como um acesso ao site e precisa de internet e permissão para acessar o endereço. Compartilhe o endereço publicado pelo seu repositório no GitHub Pages. O desempenho depende do computador e do navegador.

Preciso de um arquivo .sav para começar?

Não é preciso importar um save pronto. A ROM cria seu próprio progresso. O navegador guarda os checkpoints localmente quando esse recurso está disponível; não limpe os dados do site sem exportar um backup. A ROM é carregada pelo site; o progresso fica no seu navegador.

DeSmuME mostra “The save data could not be accessed”. E agora?

Essa mensagem indica falha ao acessar a memória de salvamento. Pode envolver o tipo de memória configurado, um save anterior incompatível ou a compatibilidade da ROM com o emulador. A causa no seu Windows ainda precisa ser confirmada.

  1. Feche o emulador e faça uma cópia dos seus arquivos .dsv e .sav.
  2. Em Config → Save Type, teste a opção de memória Flash de 4 Mbit (512 KB), compatível com a base HeartGold. O nome do menu pode variar conforme a versão.
  3. Para testar sem alterar seu progresso, use uma cópia da ROM em outra pasta, com um nome novo, e abra normalmente, sem importar save ou carregar save state.
  4. Se continuar, anote a versão completa do DeSmuME e a configuração de Save Type. Essas informações ajudam a reproduzir a falha.

Quais Pokémon podem aparecer?

Kanto usa espécies da Gen I; Johto usa Gen I–II; Hoenn usa Gen I–III; Sinnoh usa Gen I–IV. Lendários e míticos dessas gerações participam da mesma seleção aleatória. Johto padrão e completo compartilham o mesmo grupo de espécies.

Posso selecionar a região aqui no site?

Os cartões apresentam cada circuito. A escolha que inicia a run é feita dentro da ROM. Seus recordes são registrados pelo próprio jogo; esta página não lê nem altera os recordes.
